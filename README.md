# Rootlore の配布

Rootlore（Mac のアプリ）の更新ファイルを置く場所です。ソースは別の非公開リポジトリにあります。

- `latest.json` … アプリが起動時と「アップデートを確認…」のときに読む案内
- Releases … 更新用の `Rootlore.app.tar.gz`（と `.sig`）

アプリは `https://raw.githubusercontent.com/tanakaisworking/rootlore-releases/main/latest.json` を見て、
新しい版があれば知らせます。中身はアプリに埋めた公開鍵で確かめ、合わないものは入れません。
